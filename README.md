# 星际运输站 · 资源调配策略

一款基于 **Phaser 3** 的空间站货运甲板调度策略游戏。你是中转空间站的调度官：不同星系的货船定期靠港卸载**矿石 / 能源 / 补给**，而装货船需要在倒计时结束前集齐特定组合的货物发往各个目的地。在有限舱位、载重限制与燃料预算下，决定临时堆放、优先转运与合并集装策略，并应对氧气泄漏、货舱损坏与海盗袭击。

## 运行方式

无需构建，纯静态页面：

```bash
# 方式一：直接用浏览器打开
open index.html            # 或双击 index.html

# 方式二：本地静态服务器（推荐）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

Phaser 已内置于 `lib/phaser.min.js`，完全离线可玩。

## 玩法规则

### 核心循环
- **卸货船**靠港后，把船上货物搬入甲板舱位；倒计时结束仍未卸完，滞留货物会拉低稳定度。
- **装货船**靠港后显示需求订单（如 `矿×2 能×1`），在倒计时结束前装载对应货物完成订单，赚取**分数 + 燃料 + 稳定度**；提前完成有时间奖励。
- **舱位限制**：每个舱位最多堆 3 箱、载重上限 9（矿石重 3 / 能源重 2 / 补给重 1）。
- **燃料预算**：搬运、合并、拆分、修复、防御均消耗燃料；燃料随时间缓慢恢复，完成订单是主要补给来源。
- **稳定度**：错失船只、超载堆放、氧气耗尽、海盗劫掠都会降低稳定度，**归零则空间站瘫痪（游戏结束）**。

### 操作
| 操作 | 说明 |
| --- | --- |
| 点击货物 | 选择 / 再点取消 |
| 点击舱位 | 将选中货物放入（消耗 1 燃料） |
| 点击装货船面板 | 装载选中货物（舱位→船 1 燃料；卸货船→装货船**优先直转** 2 燃料） |
| 点击同类货物 | **合并集装**（单箱最多 3 件，消耗 2 燃料） |
| 选中后点【拆分】 | 分离堆叠（消耗 1 燃料） |
| 右键 / ESC | 取消选择 |
| 空格 | **暂停规划**（时间冻结，仍可操作） |
| Z / 【撤销】 | **撤销**上一步货物操作（最多 30 步） |
| M | 静音开关 |

### 突发事件
- **氧气泄漏**：氧气持续下降，归零后稳定度快速流失 —— 花 3 燃料修复。
- **货舱损坏**：随机舱位停用 20 秒 —— 可花 2 燃料立即修复。
- **海盗袭击**：9 秒倒计时后劫掠甲板货物 —— 花 5 燃料启动防御炮台。

### 难度航线（3 条，递进）
| 航线 | 难度 | 泊位 | 舱位 | 特点 |
| --- | --- | --- | --- | --- |
| 半人马座航线 | ★☆☆ | 2 | 12 | 时限宽松，事件稀少 |
| 天狼星航线 | ★★☆ | 2 | 10 | 节奏加快，订单复杂 |
| 银河核心航线 | ★★★ | 3 | 10 | 高频到港，危机频发 |

各航线最高分独立保存在 **localStorage**（键：`sts_best_v1`）。

## 合同模式（航线合同与动态市场）

主菜单顶部可切换 **⚙ 经典模式 / 📜 合同模式**，两种模式相互独立：

- **3 份随机合同**：每局开始随机公示 3 份合同，每份包含**目标目的地、货物组合、完成数量、截止时间、奖励倍率**（参数随航线递进）；玩家可同时接取 **1～2 份**，弃单不罚。
- **合同匹配**：合同模式下大部分装货船发往在执行合同的目的地，订单货物即合同组合；泊位与队列会以「📜合同」标识。装货订单完成后按**目的地 + 当前市场价格**结算合同进度、分数与燃料（目的地相同的散单也计入对应合同）。
- **动态市场**：矿石 / 能源 / 补给价格每 **60 秒**波动一次（±25%，有上下限），右侧「市场行情」面板实时显示价格与相对基准价的涨跌。
- **结算公式**：`基础收益（基准货值 × 合同倍率） + 行情加成（(市价−基准) × 倍率） + 时间奖励（剩余秒数）`，另固定 +8 燃料 / +4 稳定度。
- **逾期惩罚**：截止时间到仍未完成的合同扣除稳定度（半人马 10 / 天狼 12 / 核心 15）。
- **结算界面**：全部合同结束（完成或逾期）后展示每份合同明细，以及**基础收益 / 行情加成 / 时间奖励**三段汇总与最终总分。
- **存档续局**：合同状态、各航线最佳合同收益（`sts_best_contract_v1`）与最近一次未结束进度（`sts_save_contract_v1`，按航线分别保存）均写入 localStorage；每 4 秒、返回菜单与离开页面时自动保存，刷新后可在菜单卡片上「继续未结束合同局」。
- 经典模式的玩法、规则与存档（`sts_best_v1`）完全不受影响。

## 界面说明
- **顶部**：分数 / 燃料 / 稳定度 / 氧气 / 计时 / 撤销·暂停·菜单按钮
- **左侧**：货运甲板（舱位堆叠状态 + 载重条 + 甲板总负荷）
- **中部**：停靠泊位（船只信息、货物/订单、**离港倒计时条**）、状态/警报面板
- **右侧**：入港队列（ETA）；合同模式额外有**合同进度**与**市场行情**面板（航线统计 / 操作指南相应精简）；经典模式为航线统计、操作指南
- **底部**：选中操作栏、调度日志

## 技术要点
- Phaser 3.80（本地 `lib/`，无外部依赖）、原生 ES6，无构建步骤
- 全部 UI 由 Phaser GameObject 程序化绘制，零美术资源
- WebAudio 振荡器合成音效（无音频文件）
- 操作快照式撤销栈、localStorage 高分持久化
- `Phaser.Scale.FIT` 自适应缩放，1280×720 设计分辨率
